## 为什么之前会反复返工

1. 冻结了动作曲线，却没有先闭合从该落点到下一次卸载的完整承载区间；间距修好后才发现力矩不足。
2. 单独 IK、端点间距和若干 CAD 姿态被提前当作整条连接路径成立；插值内点、速度和真实支撑交接随后又推翻路线。
3. 报告常在第一个失败处停止，修补后才暴露早已存在的下一类错误；没有集中输出同一候选的全部可判定缺陷。
4. 版本号增长代替了里程碑；没有计算预算耗尽或物理假设被否决时的退出规则。

处理办法：先固定接触图、最终区域和误差预算，再联合审查所有连接段。失败处以下若已无合法连续入口，标 `BLOCKED_BY_ENTRY`，不能独立 IK 重启制造通过；仍可独立判定的结构、空间及端点错误全部一起列出。

## 全局接触顺序与动作取舍

- 从最终姿态反推：机身 XY `(.450,-.063)`，候选 z `.295 m`；六足最终 XY 为 LB `(.375,.030)`、LF `(.555,.045)`、LM `(.480,.105)`、RB `(.400,-.230)`、RF `(.605,-.230)`、RM `(.500,-.255)`。这些是待验候选，不能压过安全 patch 和连续可达性。
- 顺序依赖：保留 RM → LF 最终支撑 → 机身预载/抬升 → RB 最终支撑 → RM 腾空 → RF 前移腾位 → 中腿最终承载 → LB 最终登台并居中。只有载荷和通道允许，才并行；并行本身不是目标。
- 不再为“六腿都落地”添加过渡点。空中保持腿在需要接替支撑之前可以继续随身前移，但不能占用邻腿的扫掠通道。
- C5/C9 以及 C12 RB 收脚分别列出删去后的支撑/工作空间反事实；未通过比较前既不删除，也不写成必需。比较归入最多两套完整方案，不另开局部试错链。
- 所有必要上台动作完成之后若还需平移，采用普通支撑/摆动步态整体前进；不增加逐腿摆正阶段。当前 C17 已同步完成最后登台和居中，不强加一段多余行走。
- 高抬腿是硬约束：按髋坐标规划最高安全路径，支撑腿伸展是抬身、不是撤去接触。限位、自碰撞和台阶扫掠共同限制最高点，不能机械给所有腿统一世界 z。
- 地面与小蓝高低区域用于粗规划；12° 外入口、5.384° 翼面和中央凸台仍是几何约束。不能因粗高度分类而把斜面、竖面或被遮盖面当成水平落脚面。

## 一张联合预检表，取代逐项试错

每个阶段和每次支撑交接同时输出以下栏目，不只保留第一个失败：

1. 入口/出口 `body/q/feet/patch/normal/support/air`、世界支撑静止性、air 连续性和真实 runtime 曲线定义；入口无效的后继标阻塞。
2. 所有固定腿从落地到卸载的连续可达性、姿态重定向、关节余量及活动腿分支；不能只审查活动腿。
3. 足、踝、膝、腿间及机身与台阶的关键扫掠；内部曲线极值与误差包络一并审查，落脚区域不能跨竖面/边缘。
4. 每个临界交接前/后、抬身/前移极值的 COM 与摩擦力/力矩可行性。静态 LP 只是否决器；另审查惯性、落脚冲击、足/结构顺应、回差与跟踪饱和，不把静态余量当动态证明。
5. 实际曲线的 qdot/加速度峰值、连续性、触地前法向接近速度与停顿理由；4 rad/s 命令基线、物理 velocity multiplier 和历史诊断 guard 分开记录，禁止混用。
6. 硬门保持：关节不得限位、余量 >.020 rad；腿间距 ≥80 mm；COM 原始余量 ≥10 mm，并报告扣除误差后的余量；CAD 跨越净空通常 ≥15 mm、接触末段间隙 [-.5,+2] mm、边缘通常 ≥15 mm；静态利用率 ≤1。接近硬门的项单独列风险，不因表格 PASS 称稳定。

优先复用哈希、入口与曲线都匹配的缓存；结构核对不调用整机仿真。CPU 与局部 CAD 只在所有独立静态缺陷已集中清除后各做一次；不跑密集全 STL 扫描，不做无界搜索。

M2 仿真验收必须区别计划支撑与实际承载：三足支撑区间要求三足都持续有载；四/五支撑可用实际承载的非共线子集，但必须有至少三足且实际姿态下模型 COM 的有符号投影余量 ≥10 mm。最终保持至少 .5 s，居中按实际 root XY 与目标距离 ≤20 mm 审查，足落在正确上表面并满足间隙/边缘门。1 N 可作为既有模拟载荷诊断阈值，不是实机接触阈值；短暂着陆冲击不能算持久承载。碰撞、滑移、姿态持续发散、执行饱和均不得由 DONE 抵消。

M3 固定工况为：初始相对 XY 四角 `(+10,+10)、(+10,-10)、(-10,+10)、(-10,-10) mm`，yaw 按 `+1,-1,-1,+1°` 配置；第五个工况为最窄落脚区域沿其最不利面内方向的 `5 mm` 目标落点偏移。偏差应施加于实际场景初始相对位姿或执行落点，不能重算一个理想初态把偏差消掉。落点偏移只验证落点选择偏差，不冒充滑移、传感器噪声或延迟测试；实施前必须冻结具体腿、方向和传播方式。五个离散工况通过也只支持这些测试点，不能证明整个误差盒或任意初始姿态。

**本轮完成定义**：M1/M2/M3 通过则冻结一个稳定性优先的仿真候选；否则在预算内给出可复现否决结论及现有基线。两者都结束本轮，不无限推进。速度与更多合并另列后续优化，必须先有本轮实际完成时间与接触次数基线，不继续占用本轮验证预算。未经用户重新定义目标或预算，不自动启动下一轮。

## 复用技巧与采纳状态

- 症状 → 根因：多轮依次发现速度、间距、力矩问题 → 接触状态和实际曲线未作联合准入。
- 修复方式：本轮只改流程；采用整套路线比较、全部独立错误汇总、带预算的阶段验收，尚未修复物理候选。
- 规则与回归：下一次写生成器前，须已有完整接触图、真实曲线及联合预检表；缺栏或旧哈希报告不能算完成。
- 适用/失效：适用于已知几何与已知初始姿态；实际起始状态/传感器标定缺失时不得自行假定。
- 已测收益：本次静态读取直接发现 C17 的 7/8 支撑表错误，避免为该输入启动 CPU/GPU；同时识别极坐标证据与执行曲线不一致，**没有**测得仿真耗时或成功率改善。
- 固化：本文件合同与 HANDOFF 入口已采纳；自动联合分析尚未实现，物理问题保持 OPEN。
